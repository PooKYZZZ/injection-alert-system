# Mock Portal Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Land Records Demo Portal install, build, persist submissions through Prisma/SQLite, expose clear WAF-visible native form routes, and present as a credible public records mock portal without adding unrelated features.

**Architecture:** Keep the app simple: React pages render UI, native HTML forms submit directly to explicit route handlers, route handlers validate and write to Prisma, and cookies are reduced to short-lived success/reference hints only. Remove hidden middleware routing for normal form flow and avoid new service layers, real auth, Server Actions, uploads, email, payments, or admin dashboards.

**Tech Stack:** Next.js App Router, React 19, TypeScript, Tailwind CSS v4, Prisma Client, SQLite, Zod, native HTML forms, npm, optional Docker after local build is healthy.
